# Todo web app

> **Status:** Active development - work in progress

Todo web app allows users to create, update and manage their personal todo lists.
It is designed to be simple and accessible from desktop browser.

---

## Installation and Usage

### Requirements

- Java 17+
- Node.js (with npm)

### First Time Setup

1. Clone the repository:

```bash
git clone https://github.com/Ugnytea/Todo-web-app.git
```

2. Navigate to the frontend and install dependencies:

```bash
cd Todo-web-app/frontend
npm install
```

3. Start the application:

```bash
npm start
```

> **Note:** First startup may take 15-30 seconds while the backend initializes.

4. Access the application on `http://localhost:5173`

### Running After Initial Setup

1. Navigate to the frontend folder and start:

```bash
cd Todo-web-app/frontend
npm start
```

2. Access the application on `http://localhost:5173`

## Features

- Create, read, update and delete tasks
- Create lists
- Organize tasks into custom lists
- Mark tasks as important
- Set due dates
- Track completion status
